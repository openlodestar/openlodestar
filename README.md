# OpenLodestar

> 给大模型的输出做证据核对：模型说的事实只当候选，逐条拿去联网取证，核完才算数。

## 这是什么

模型脑子里记着很多事实，但它说出来的每一条都不带证据。OpenLodestar 想试的是另一条路：**把模型说的事实只当候选，逐条拿去联网核对，核完才让它算数**——每条结论后面挂一条能重跑的证据链。

## 设计取向

- **生成的东西只当候选，永不当结论**。可以让模型先列一批它"记得"的东西，但列出来的必须逐条过了证据才作数；"先生成"不放松后面的核对。
- **证据池不许自证**。核对用的证据只来自外部公开来源，不用自己采集的语料去验证自己产出的东西。
- **能重跑比能跑通重要**。每条结论都留下完整的检索与判定过程，错了要能定位到是哪一步错的。

## 当前状态

**早期实验阶段，尚无可用代码。** 目前在做的是把一条最小链路跑通并记录过程，代码尚未开源。
