# OpenLodestar

> 把"考据式核验"做成可运行的开源引擎：给一个检索任务，还你一份可核验的记录清单。
> An open-source engine for verifiable record discovery — from a retrieval task to a list of cross-verified records.

> **本项目与 ChainSafe 的以太坊共识客户端 Lodestar 无任何关系。** 它是 AI 检索与核验方向的独立项目，名字取自"北极星"（lodestar）这一语义。
> Not affiliated with ChainSafe's Lodestar (Ethereum consensus client).

## 它解决什么问题

输入一个任务，比如「找有民窑瓷器的拍卖会」，输出的不是一段文字回答，而是一份**逐条带出处、可被复核的记录清单**——这份清单可以直接当作后续采集任务的种子。

## 三条设计取向

1. **大模型说的只算候选。** 生成的每条记录都要回到独立来源上核对。
2. **两个以上独立来源对上才算数。** 单来源的说法不采信。
3. **「没找到」是合法答案。** 核不出来就报空，不编造、不拿低置信度的内容凑数。

一条来自实测的教训：纯靠模型参数记忆做枚举（直接问它"列出近五年某拍卖行的专场"）在专业垂域基本问不出东西。所以当记忆复问全部落空时，本项目会退到检索增强路径——先搜一次，再基于同一份材料做提取式复问，两轮结果行级一致才放行。

## 当前状态

已经做完：

- 端到端最小回路跑通：任务输入 → 逐条列举提问 → 逐字段裁决 → 共现门禁 → 输出记录
- 检索增强兜底、检索与抓取预算上限、同记录内抓取结果复用等机制已实测

还没有做：

- **代码尚未开源**，仍在内部仓库整理、补文档；开源时一并发布
- 目前只在「中国古玩拍卖」这一个垂域实测过，换领域是否成立未经检验
- 许可证待定，开源时确定
