# 断言类型分支的端到端落点

> 配套测试：`src/lodestar/branch-landing.test.ts`（离线，9 例）
> 复跑：`npx vitest run src/lodestar/branch-landing.test.ts`

冻结语料里的 39 条断言全是「某拍行某年举办某专场」这一类存在型命题。策略包里另外五个分支——物品级个体断言、聚合统计、未来事件、自指、主观评价——此前只有策略包层的单测，没有一条走完「入库 → 路由 → 检索（或拒收）」的整条链。这份文档记录那五个分支各一条句子级样本的实际落点，外加两个错误方向的样本。

## 怎么跑

样本走**外部提交**渠道：`externalClaimToRecord` 把一句话转成断言契约，`runQuery('', { externalClaims })` 送入引擎。这条渠道不经过提问环的预筛，所以五个分支的落点都从**路由**开始——这是渠道设计，不是漏了一步。

离线只换了两段：

| 段 | 用什么替换 | 说明 |
| --- | --- | --- |
| 检索 | `frozen-stub` 提供者，永远返回空结果 | 查询构造、预算计数、候选过滤仍走真实代码；不发网络请求 |
| 查询翻译 | 固定返回 `failed: true` | 检索退回单轨，`searchCalls` 就等于实际查询条数 |
| 聚合拆分 | 一段固定的模型应答（一条子断言） | 只有聚合统计那条样本会用到；其余样本不触发拆分 |

其余全部是真代码：断言契约、路由、检索编排、底稿写入、计票。没有抓页、没有比对调用、没有联网、没有 Serper。

## 逐条解释

### 第 2 行：聚合统计拆成了什么

父句「成交率为 82%」不能直接裁——网页上很难找到一句写着同一统计口径的话。拆分后得到的子断言是：「中国嘉德于2021年11月举办秋季瓷器专场」。这是一条标准的存在性断言，路由送核，检索发出 4 条查询：主体加客体、原句，以及两条站内定向。父断言自己一次检索都不发，花费全部记在子断言上。

### 第 4 行：未来事件的相对说法（规则错）

规则判断未来事件的方式是：在句子里找四位年份，年份大于当前年就拒收。这能挡住「2028 年将办」，挡不住「明年将办」「后年将办」「下一年将办」——这些句子里根本没有四位数字，于是整条送去核，白花 4 次检索。

这是规则错，不是样本刁：句子表达的确实是未来事件，只是用了相对时间词。修法也直接——把「明年 / 后年 / 次年 / 下一年」这类相对年份纳入同一道判断，按当前年换算；但这一轮只做落点盘点，没有改路由。

### 第 7 行：主观评价的口语说法（规则错）

主观评价分支靠一张封闭词表：最精美、极具价值、值得收藏、艺术价值极高。书面评语能挡住，口语说法挡不住。「我认为这是真品」既没命中词表，也不含「这件 / 该件 / 此件」，于是落到可核分支，花 4 次检索去查一句个人判断。

这也是规则错：真伪判断没有网页证据可裁，应归主观评价（或另立一档「不可裁的个人判断」）。词表需要补口语框架（我认为 / 我觉得 / 个人认为）与真伪判断词（真品 / 赝品），并按整句命题判断，而不是只认书面形容词。

### 第 8 行：含主观修饰的可核断言（规则错，漏判方向）

句子的事实内核是「中国嘉德 2021 年办了秋季瓷器专场」，正是冻结语料里最常见、也最该核的存在性断言；后面跟了一句营销口吻的「值得收藏的官窑重器」。现规则按子串命中「值得收藏」，整句拒收——事实内核跟着一起没了。

这是漏判：该核的没核，而且从读数上看与「这条本来就不可裁」无法区分。它算规则错而不是样本刁：样本是模型真实会说的话（事实加评价混在一句里），错在判据只看子串、不看命题的主谓结构。可行的修法有两种——一是把这类混合句送拆分，保留可核的存在性部分、丢掉评价部分；二是只在谓语或宾语本身是评价时才整条拒收。两种都超出这一轮的范围。

### 第 1、3、5、6 行：四个分支的正常落点

第 1 行按「这件 / 该件 / 此件」识别物品级个体断言；第 3 行按四位未来年份识别未来事件；第 5 行按「训练数据 / 预训练 / 我的记忆 / 模型记忆」识别自指；第 6 行按词表识别主观评价。四条都在路由层整条拒收，一次检索都不花，也不产生裁决行——拒收本身就是正式产出。

## 已知边界

- 五个分支各只有一条样本，证明的是「这条链路能走通、落点可观测」，不是完整分类学。词表与正则的覆盖缺口（第 4、7、8 行）要继续用真实越界句扩充样本。
- 外部提交渠道不经过提问环预筛。若要覆盖预筛层的拒收（稳定性不足、指代未消解等），需要另起一份走提问环的样本，不在本表范围。
- 检索段是冻结桩，所以只验证「发了多少条查询」，不验证「这些查询能不能召回真页」。后者属于在线实验，按仓库约定要单独报预算。
