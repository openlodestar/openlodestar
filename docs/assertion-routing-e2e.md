# 断言类型分支的端到端落点

> 配套测试：`src/lodestar/branch-landing.test.ts`（离线，9 例）
> 复跑：`npx vitest run src/lodestar/branch-landing.test.ts`

冻结语料里的 39 条断言全是「某拍行某年举办某专场」这一类存在型命题。策略包里另外五个分支——物品级个体断言、聚合统计、未来事件、自指、主观评价——此前只有策略包层的单测，没有一条走完「入库 → 路由 → 检索（或拒收）」的整条链。这份文档记录那五个分支各一条句子级样本的实际落点，外加两个错误方向的样本。

## 怎么跑

样本走**外部提交**渠道：`externalClaimToRecord` 把一句话转成断言契约，`runQuery('', { externalClaims })` 送入引擎。这条渠道不经过提问环的预筛，所以五个分支的落点都从**路由**开始——这是渠道设计，不是漏了一步。

离线只换了两段：

| 段 | 用什么替换 | 说明 |
| --- | --- | --- |
| 检索 | `frozen-stub` 提供者，永远返回空结果 | 查询构造、预算计数、候选过滤仍走真实代码；不发网络请求 |
| 查询翻译 | 固定返回 `failed: true` | 检索退回单轨，`searchCalls` 就等于实际查询条数 |
| 聚合拆分 | 一段固定的模型应答（一条子断言） | 只有聚合统计那条样本会用到；其余样本不触发拆分 |

其余全部是真代码：断言契约、路由、检索编排、底稿写入、计票。没有抓页、没有比对调用、没有联网、没有 Serper。

## 逐条解释

### 第 2 行：聚合统计拆成了什么

父句「成交率为 82%」不能直接裁——网页上很难找到一句写着同一统计口径的话。拆分后得到的子断言是：「中国嘉德于2021年11月举办秋季瓷器专场」。这是一条标准的存在性断言，路由送核，检索发出 4 条查询：主体加客体、原句，以及两条站内定向。父断言自己一次检索都不发，花费全部记在子断言上。

### 第 4 行：未来事件的相对说法（2026-11-09 已修）

原规则只在句子里找四位年份，年份大于当前年就拒收；「明年将办」没有四位数字，于是整条送去核，白花 4 次检索。

现在的判断分两步：先把句子里所有四位年份取出来，任一晚于当前年就拒收；再看相对年份词（明年 / 后年 / 来年 / 下一年），命中且**没有过去年份在场**时也拒收。加「没有过去年份」这个条件，是为了不误杀「2021年办过，明年将办下一届」这类混合句——有过去年份时放行去核，宁可花检索。代价是只提未来、但句中恰好带一个过去年份的混合句仍会送核。

「次年」没有纳入：它相对的是句子里已经写出的那一年，可能是过去（「2021 年秋拍，次年春拍」指的是 2022 年），盲目按未来拒收会误杀可核断言。

### 第 7 行：主观评价的口语说法（2026-11-09 已修）

原词表只收书面评语（最精美、极具价值、值得收藏、艺术价值极高），「我认为这是真品」既不命中词表，也不含「这件 / 该件 / 此件」，于是落到可核分支，花 4 次检索去查一句个人判断。

现在主观评价分支看**命题字段**（谓语 + 宾语），在原有评价词之外补了真伪判断词：真品、赝品、真迹、仿品、真伪、真假。真伪是鉴定意见，网页证据裁不了，归主观评价。这个样本的宾语是「真品」、谓语是「真伪判断」，两道都命中。

### 第 8 行：含主观修饰的可核断言（2026-11-09 已修，漏判方向）

句子的事实内核是「中国嘉德 2021 年办了秋季瓷器专场」，正是冻结语料里最常见、也最该核的存在性断言；后面跟了一句营销口吻的「值得收藏的官窑重器」。原规则按子串命中「值得收藏」，整句拒收——事实内核跟着一起没了。

现在改为**只看命题字段**：评价词出现在谓语或宾语里才整条拒收；只出现在原子句、主语或修饰语里，不改变命题性质，照常送核。选的是「只在谓语／宾语本身是评价时才拒收」这条路，没有走「混合句送拆分」，因为这条句子的事实内核就是完整的存在性断言，不需要再拆一层，直接核更省一次模型调用。

**这条规则会失效的场景**（会被误判成可核、照常花检索）：

1. **提取把评价写进了主语或原子句，谓语／宾语却是中性词。** 例如同一句话若被抽成主语「值得收藏的官窑重器」、谓语「上拍」、宾语「2021年秋拍」，评价在主语里，规则看不见，整句送核。
2. **评价是隐晦说法，没有词表里的词。** 例如「这场拍卖会堪称年度盛事」「这件东西难得一见」——没有「极具价值」这类词，规则认不出是评价，送核。
3. **真伪判断被抽成中性字段。** 例如「我认为这是真品」若被抽成谓语「认为」、宾语「这」，宾语里没有「真品」，也会送核。
4. **一句话里既有可核事实又有纯粹的口头判断，且判断落在谓语上。** 例如「这场专场办得很成功」——「成功」不在词表里，会送核；这类句子即使送核，也很难从网页得到「一致／矛盾」。

这四条是结构判据换来的代价：它保证「句尾带评价词的可核断言」不被误杀，代价是「评价没落在命题字段里」或「评价用词不在表里」时会漏拦。要继续收窄，得补词表或让提取层把评价单独标出来，不是再加子串规则。

### 第 1、3、5、6 行：四个分支的正常落点

第 1 行按「这件 / 该件 / 此件」识别物品级个体断言；第 3 行按四位未来年份识别未来事件；第 5 行按「训练数据 / 预训练 / 我的记忆 / 模型记忆」识别自指；第 6 行看命题字段里的评价词（这条样本的谓语是「评价」、宾语是「极具价值」）。四条都在路由层整条拒收，一次检索都不花，也不产生裁决行——拒收本身就是正式产出。

## 改完之后的冻结读数

同一批样本改完后重跑：39 条冻结断言的逐条路由（分支 / 档位 / 理由）与 82 条证据重算出来的裁决，和改前逐行相同。验证方式不是抽查，是对七批冻结底稿逐条生成路由快照再做文本比对（`claims=39 evidence=82`，零差异），七批 demo 的裁决输出也零差异。

## 已知边界

- 五个分支各只有一条样本，证明的是「这条链路能走通、落点可观测」，不是完整分类学。结构判据的失效场景（见第 8 行下面四条）要继续用真实越界句扩充样本。
- 外部提交渠道不经过提问环预筛。若要覆盖预筛层的拒收（稳定性不足、指代未消解等），需要另起一份走提问环的样本，不在本表范围。
- 检索段是冻结桩，所以只验证「发了多少条查询」，不验证「这些查询能不能召回真页」。后者属于在线实验，按仓库约定要单独报预算。
