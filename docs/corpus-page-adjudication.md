## 一、日期判据：哪些差异可以归一，哪些不可以

判据先按旧口径逐字比；不中时，把断言与页面里的日期**都归一成日历日期**再比。归一只改"怎么比"，不改"拿什么当证据"——返回的 `quote` 一律是从页面正文里切出来的原样片段。

**可以归一（同一件事的不同写法）：**

| 差异 | 例子 | 归一结果 |
| --- | --- | --- |
| 月份全称 / 缩写 / 带点 | 断言 `12 December 2023`，页面 `12 Dec 2023` | `2023-12-12` |
| 日-月-年 与 月-日-年 语序 | `6 November 2024` 与 `November 6, 2024` | 同一天 |
| ISO 串 / 带时区时间戳 | `2026-09-23T04:20:00+00:00` | 只看日期部分，时区不改日期 |
| 中文日期 | `2021年12月5日` | `2021-12-05` |
| 页面只写月日、年份在 URL 且唯一 | `November 6` + URL `/buy/auction/2024/…` | `2024-11-06`，`yearSource: 'url'` |

**不可以归一（一律判不中，不猜）：**

| 情形 | 为什么 |
| --- | --- |
| 日、月、年任一不同 | 那不是同一天 |
| 页面只写到月（`December 2023`、`2023年12月`） | 不是某一天，不能补成 1 日 |
| 斜杠日期（`03/04/2023`） | 日/月语序两套习惯都成立，分不清就不判 |
| 两位数年份（`12 Dec 23`） | 世纪有歧义 |
| 页面没写年份、URL 也没有独立年份 | 用断言本身推年份等于循环论证，记「缺年」 |
| URL 里有多个不同年份 | 分不清哪个是场次年，记「缺年」 |

样本里五页的命中变化：

| 页面 | 改前（逐字） | 改后（归一） | 引文（逐字） |
| --- | --- | --- | --- |
| Christie's `lot-6463050` | ✗ | ✓ 归一 | `12 Dec 2023` |
| Sotheby's `chinese-art-3` | ✗ | ✓ 归一（年份取 URL 的 2024） | `November 6` |
| christies.com.cn 模板 | ✗ | ✓ 归一 | `2026-10-29T06:45Z` |
| Bonhams `lot/21` 模板 | ✗ | ✓ 归一 | `2026-09-23T04:20:00+00:00` |
| Bonhams `lot/27` 模板 | ✗ | ✓ 归一 | `2026-11-02T10:00:00+00:00` |

注意：**模板页也全中了**。这不是判据的胜利，而是"模板会自证"的证据——它们本来就是抽取器写进去的日期。所以模板页不进两字段分母，只记「材料不够」。

## 二、机构判据：命中必须落在结构位置，并接受语言差异

判定分两步：**先看这一串字出现在页面的什么位置，再看它是不是同一家机构的另一种写法。**

**算证据的位置（只有这四个）：**

| 位置 | 抓取方式 | 典型内容 |
| --- | --- | --- |
| 页头 / 站内导航 | `<header>`、`<nav>` | 拍行站名与返回本场次的导航 |
| 面包屑 | class/id/aria-label 含 `breadcrumb` 的容器 | `Christie's › Auctions › …` |
| 标题区 | `<title>`、`<h1>` | `Bonhams : Fine Chinese Ceramics…` |
| 场次抬头 | class/id 同时含 `sale|auction` 与 `title|name|heading|header` 的容器 | 场次页的抬头块 |

**不算证据的位置（出现多少次都不算）**：正文段落与图注（「此器曾售于佳士得」是转述）、推广卡片与相关拍品（`illustrated with pieces offered at Christie's` 是在推销别场）、员工邮箱与电话、页脚版权与免责声明、图片 alt 与 og/meta 标签。这些只证明"页面里出现过这串字"，不证明"这一页是这家拍行的场次/拍品页"。

**为什么改**：旧口径是「机构名在整页任意位置最早出现即命中」。真实原文页 `christies.com.cn/en/lot/lot-6608461` 上，机构名只出现在员工邮箱 `malmeida@christies.com` 和一张推广卡片里，旧口径判成命中；这一页的页头/面包屑/标题区/场次抬头里**没有任何拍行明文**，正确结论是「判不了」。改后该页实测：机构 `unjudgeable`、位置 `null`，日期仍是 `normalized`（引文 `29 Oct 2026`），两字段因此不成立。

别名部分不变，仍复用 `canonicalHouseName` 与 `HOUSE_ALIASES`（查询构造、标题冲突判据共用同一份）：

- `Christie's` 与「佳士得」是同一家；`Sotheby's` 与「蘇富比 / 苏富比」同理；
- 断言不在词表里时（如 `Finarte`）只做逐字比对，不靠相似度硬猜；
- 引文取结构位置上**实际出现的那一种写法**，并跳过落在域名/URL 里的命中；
- `heritage` / `guardian` / `council` 这类本身就是普通英文词的别名，从匹配中剔除（与标题冲突判据共用同一份黑名单）；
- 四个区域都抽不出来（或抽出来但都没有拍行明文）→ 记 `unjudgeable`（判不了），不记 `absent`（没有）：前者是"这一层材料不足以证明归属"，后者会把材料不足说成结论。

**这条改法会漏掉哪些真命中（如实写清代价）：**

1. 拍行名只出现在 `<img alt>` 或 CSS 背景图里，页面没有可读的页头文本；
2. 站点不用 `<header>/<nav>`，页头是 `<div class="top-bar">` 这类无可识别语义的容器；
3. 场次抬头是 `chr-event__title` 这种命名里不含 `sale/auction` 的容器，抽不到；
4. 单件页面包屑只写「Live Auction 21663」这类编号、页头只放 logo 图片。

这四种都会判成「判不了」而不是「命中」。这是有意的取舍：宁可少认一页，也不把邮箱与推广位当成归属证据。要补这些站点，应当按站点补一条结构映射（哪几个选择器算页头），而不是退回整页扫描。

**还剩下的误判风险**（结构位置本身也会说别的事）：

1. **面包屑写递藏来源**：少数站点把「旧藏：佳士得」放进面包屑，那不是本场主办方；
2. **普通词/同名机构**：汉字两字别名（保利、嘉德）会命中「保利剧院」「嘉德置地」这类语境，出现在页头里同样会误判；
3. **同页多机构**：媒体稿同时提苏富比与佳士得，任一别名都会命中——所以媒体稿（`kind: 'article'`）不进裁决。

### 机构拿不到明文时：降为域名断言，不升级成证据

机构在可见明文里拿不到时——佳士得中文站就是这样，拍行名只以图形标识出现——**把机构降为一条域名断言**：页面落点域的主域名与断言机构在别名表里对得上（`christies.com.cn` ↔ `Christie's`）。它记一条，形态是：

| 项 | 取值 | 含义 |
| --- | --- | --- |
| 证据种类 | `domain` | 与逐字证据并列，不是它的一种 |
| `verbatim` | `false` | 不是页面明文 |
| `quote` | `null` | 没有可回链的引文 |
| 内容 | 落点主域名 | 断言的全部内容就是「这个页面在谁家的域名下」 |

口径写死四条：

1. **不进逐字证据**：拿不到明文的机构仍然是 `unjudgeable`，不能因为域名对得上就改写成 `hit`；
2. **不进三字段分母**：三字段只认「同一张场次页上、机构 + 专场名 + 举办日期三样都是可见明文」。机构字段只能出域名断言的场次，整场按场次层契约记「两字段」或「未测」，不得计入三字段的分子或分母；
3. **不许用渲染、JSON-LD / meta 把它补成明文**：这三条各自是独立档位（渲染见《场次层证据》里那次只渲染一页的实测，只救回日期、机构仍未出现），混进来就是把「查不到」写成「查到了」；
4. **不许先记域名、再当成机构命中**：域名断言回答的是「这页大概是谁家的」，不是「这页上写着谁」。

**现状上限（写死，不再重算）**：这批 46 条真事件里，三字段可核 **29 条 = 63.0%**，全部来自 Bonhams；Christie's 的 **17 条结构性卡死**——机构名只在图形标识里，可见明文拿不到。63.0% 就是可见明文口径的上限，渲染、JSON-LD/meta、域名断言任何一项都不许加进这个分子。

## 三、专场字段：必须链到场次层

原来的说法「单件页（拍品详情）本来就不写专场名」经场次表的真材料校验后要收紧：**这些字段在单件页上不能当稳定出处**，但不是"一概没有"。46 条真事件里唯一一页可读原文（Christie's 中文站）就在面包屑里逐字写着 `Live Auction 21663 / Important Chinese Ceramics and Works of Art`；同一页的机构名却只出现在域名、邮箱与一张推广卡片里，正文没有可当证据的拍行明文。所以准确的病因是：**专场名在部分站点写、部分不写；机构名在单件页上通常只以域名/logo 出现**。场次层契约仍然必要，但理由改成"单件页不承担稳定出处"，不是"结构上一定没有"。实测与两条路的取舍见 [session-layer-evidence.md](./session-layer-evidence.md)。

### 场次层最小契约

| 字段 | 必填 | 内容 | 缺了怎么标 |
| --- | --- | --- | --- |
| `sessionKey` | 是 | 稳定关联键（sessionId 或规范化后的场次 URL） | 缺 → 单件挂不上场次，整页场次维度「未测」 |
| `sessionName` | 是 | 专场名，保留场次页原文与语种 | 缺 → 「未测」（不拿单件页的 slug 顶替） |
| `sessionDate` | 是 | 举办日期（ISO），不从单件事件日期反推 | 缺 → 「未测」 |
| `houseCanonical` | 是 | `HOUSE_ALIASES` 规范名，场次记录自带 | 缺 → 「未测」 |
| `language` | 是 | 专场名语种（`en` / `zh`） | 缺 → 「未测」（语种不明就不能逐字比） |
| `sessionUrl` | 否 | 场次页本身，用于二次核验 | 缺不影响判定 |

规则只有一条：**5 个必填字段齐了才判，缺一项就记「未测」，不记 0。** 0 的意思是"判了但没中"，未测的意思是"材料不在这一层"。

本轮的 10 页里，4 页可裁决页最好的一页只有 `saleUrl`（关联键），专场名、场次日期、机构、语种都没有；另 2 页连 `saleUrl` 都没有。所以：

- `sessionMeasured = 0`；
- 评分卡的「三字段可核率」显示**未测**，不是 0%；
- 契约满足之后（库里出现带齐 5 个必填字段的场次记录），同一套判据自动从「未测」切到实判，不需要改判据代码。

Finarte 那页（正文「Fine Asian Art」+「Milano」，URL slug 是 `milan`）就是契约里 `language` 字段要解决的例子：同一场次的语言差异要由**场次别名表**处理，不能靠模糊相似度硬判，所以这类情况记为 `language-mismatch` → 未测。

## 四、评分卡：三档分开，材料与判据不混算

| 分项 | 当前读数（2026-11-24 重判） | 分母 | 这一档回答什么 |
| --- | --- | --- | --- |
| 正文可读率（已入库页面） | **100.0%（10/10）** | 抽到的全部页 | 材料在不在（≥200 字符算可读） |
| 两字段可核率（机构+日期） | **25.0%（1/4）** | 可裁决页：原始正文且可读 | 判据在真页面上判不判得中 |
| 三字段可核率（+专场） | **未测** | 场次层契约已满足的页（当前 0 页） | 场次事实能不能核——材料不在单件页 |

被排除在分母外的，逐类点名（这就是"材料不够"与"判据判不中"的界线）：

- 抽取器模板 **3 页**：会自证，不能当证据；
- 媒体稿 **3 页**：不构造拍行断言，记「不适用」；
- 不可读 **0 页**；正文卡在 5 万字符 **2 页**（仍未影响本轮的机构/日期命中）；
- 判据判不中：结构位置没写机构 **—**（该计数由原先的"机构没写"改名而来）· 日期不符/没有 **0** · 日期缺年 **0**。

> **2026-11-24 重判已做**：经主人授权，从主项目库只读重导出 10 页正文（一条 `SELECT`，会话设只读），按新口径整体重判。结果与上文第五节的逐页推算**不一致**，以下表为准。差别的根源：推算时假设「结构区域在文本快照上抽得出来」，实际 `content_snapshot` 是处理后的纯文本，`<header>/<nav>`/面包屑 class 这类标记不存在——结构区域抽不出 → 机构判「判不了」而不是「没有」（这是判据设计好的行为）；4 页可裁决页里 3 页因此判不了，只有 bonhams `lot/42` 的快照恰好保留了部分结构标记而命中。日期判据不依赖结构标记，4 页全部核上。**结论：两字段这一格要上去，先补结构材料（存原始 HTML 或按站点做文本结构映射），不是放宽判据。**

原有八项读数（门禁一致率、该拒的拒了、该核的没误拒、可追溯率、静态自洽召回率、可核率、抓页成功率、逐字核验通过率、检索条数）本轮**没有变化**：判据与样本都没动它们，脚本重跑无退步红标。新增三项以「—」为基线（历史行还没有这三项），等下一轮再定基线。

**为什么「判不了」这么多**：`extractHouseRegions` 靠标签与 class/id 的正则定位页头、面包屑、标题区、场次抬头四个区域；而库里的 `content_snapshot` 是抓取时 HTML 处理器的**纯文本输出**，标签已剥掉。文本快照上四个区域抽不出任何内容 → 判据按设计记「判不了」（不是「没有」）——材料不足以定位结构，就不下结论。唯一命中与唯一换版后命中的两页（`lot/42`、`lot/27`），都是快照里恰好残留了可定位的结构标记。**这一格要上去，路径是给裁决侧补可定位的材料：存原始 HTML，或按站点做文本结构映射（如取首 N 行当页头）；不是放宽「逐字 + 结构位置」的口径。**

## 六、这个改法会误判的三种情形

1. **同一日期出现在别的语境**。页面常把递藏、展览、旧图录的日期写在同一屏（Sotheby's 那页就有 2013/2020/2021 的多个日期）。断言日期只要在文中任意位置出现一次就算命中，判据分不清"这是本场日期"还是"这是这件东西上次露面的日期"。归一只会让这个漏洞更容易被触发（写法不同的同一日期现在也会命中）。
2. **机构别名出现在结构位置、但讲的不是本场主办方**。整页扫描的转述性命中（「旧藏于佳士得」「曾由苏富比释出」）已由结构位置规则挡掉；剩下的漏洞是这句话恰好写进了面包屑/页头，或者汉字两字别名命中了同名公司、剧院、地产项目。
3. **URL 年份补全把日期带偏**。Sotheby's 这类页面只写 `November 6`，年份取自 URL。若 URL 里的年份是栏目年/归档年而不是场次年，或页面写的是预展日期（预展常在拍卖前一日），归一后会把日期判到另一年的另一件事上。当前只在 URL 里**恰好一个**四位年份时才用；多候选一律记「缺年」。

## 七、库里的材料结构（上一轮结论，仍然成立）

| --- | --- | --- |
| 原始页面正文 | 不含「拍品详情，页面地址」等模板标记 | **115** |
| 抽取器模板 | 含模板标记 | **103（47%）** |

这条结构决定了：**裁决必须只认原始正文**；也决定了"正文可读率 100%"只是在 10 页样本上成立，库级可裁决材料的真实比例约 53%（115/218）——下一轮若要报库级读数，分母应当是全库而不是这 10 页。

## 八、判断、代价与失效条件

**判断不变：Lodestar 的默认形态是「给已采集的页面做裁决」，不是「自己上网找证据」。** 这一轮补的是判据侧：写法归一让"页面写了但断言写法不同"不再被误判为"页面没写"；场次契约让"专场判不了"如实显示为未测，而不是伪装成一个 0。

代价：

- **归一判据要接受上面三种误判**，尤其是同页多日期的语境混淆；引文逐字只能保证"这句话在页面上"，保证不了"这句话在讲本场"。
- **专场维度在契约满足前一直是未测**，也就是评分卡上一直有一格不能用来比较。这是有意留白，不是遗漏。
- **样本小**：可裁决页只有 4 页，100% 是 4 页上的 100%，不是库级的 100%。

失效条件：

- 出现"页面写了日期但语境不是本场"成为多数（例如大量递藏信息混排的图录页）→ 归一后的命中会系统性偏高，需要引入"日期附近的场次名/地点"共现约束。
- 场次记录长期不落库（`sessionName` / `sessionDate` / `language` 一直缺）→ 三字段这一档永远是未测，应当考虑把它从评分卡里移出，而不是留着当装饰。
- 站点改用登录墙或脚本壳，原始正文占比继续下降 → 可裁决页先变少，两字段读数会变成"少数页上的高比例"，失去代表性。

## 九、边界与外部调用

- **只读库**：重判时用一条只读 `SELECT` 把 10 页导出成 JSON；没有写库、没有改主项目代码、没有改采集代码。
- **外部调用：0**。没联网、没抓页、没渲染、不碰 serper、不调 LLM。评分卡两次重跑输出逐字一致。
- **冻结样本不存全文**：只存 URL、字数、正文哈希、断言、逐字段判定（含引文片段）与 300 字摘录。删掉样本不影响主项目，只影响这三项评分卡读数。
- **本轮不覆盖**：登录墙后的内容、图片、价格字段的逐字核验、场次页自身的可核率、库级（218 页）抽样读数。
