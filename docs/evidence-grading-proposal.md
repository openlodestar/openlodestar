# 证据分级：把判据做成可插拔的维度

## 结论与代价

今天判时间，明天要判“北京嘉德”和“在北京市的嘉德”是不是同一家。每类都改核心，规则越堆越乱。让维度（判断证据有多直接的规则）各自独立、汇总层只认状态；代价是证据行加三个字段、重跑评估。

## 三层

抽取层（从原文摘值的环节）只取“这句话在本维度上说了什么值”，能逐字回原文，不判真假。判据层（比值的环节）每维度一份纯函数，不读库、不调模型。汇总层（折算结论的环节）只认状态，决定计不计支持、进不进共现（同一网页写出关键字段）、能不能升强坐标（交给下游的记录）。

## 维度契约

新增维度只需注册一份实现：维度名（域:字段）、取值形态、比较函数（返回状态加说明）、擦边规则、缺失处理、能否独立支撑、权重上限、状态文案。比较函数只给状态、不给分数。擦边只写在维度实现里——时间的擦边是范围挨上，机构名是“带地点限定词但同城”；汇总层不许出现季节、城市这类硬编码。

一句话跨两维（“2021年秋季 北京嘉德”）：一行只记一个维度，同一段引文各记一行、共享来源、各带自己的值。状态属于某个维度，一行塞两个说不清冲突；拆行后逐维相加互不干扰，代价是行变多、来源须去重。

## 五态

**完全对上、相容、明确冲突、没对上、无从判断。** 相容再带一档强度（不拆第六态：相邻两态那条线本就模糊）：

- 完全对上：值相同或只差写法，可进共现、可撑强坐标。
- 口径相容：同一件的不同说法或颗粒度（秋季对 8 月），可撑强坐标、不进共现。
- 边缘相容：范围只是挨上（秋季对 12 月 5 日），只抬可信度，绝不判“对”。
- 明确冲突：只作候选，不自动判反对（仍看立场与护栏），但否决强坐标。
- 没对上：按无关处理。
- 无从判断：没提到、解析不出、非同一对象；缺失维度不进分母、不扣分，也不算已证。

## 汇总与判定顺序

分量：关键维度上限 1.0，次要 0.5（领域包即按领域分组的策略插槽，由它声明）。得分：完全对上记满、口径相容 0.7 倍、边缘相容 0.3 倍，其余记 0。按顺序判：

- 逐维取状态（老行缺字段记无从判断）。
- 任一维明确冲突 → 直接判弱坐标并结束；冲突不计条数——是不是同一件只有一个答案。
- 累计分，缺失维度不进分母。
- 累计 ≥ 1.2 且至少两维各过 0.7 倍上限 → 强坐标，并写出一句依据（哪两维对上了）。
- 累计 > 0 → 弱坐标；等于 0 → 无坐标。

数从直觉来：两条相容 1.4 过线，相容加边缘 1.0 不过线；单条全对 1.0 低于 1.2；三条边缘 0.9 也升不了强。

反直觉后果：除声明可独立支撑的维度外，没有单一维度能单独构成强坐标，必须两维起步——这合乎人的判断，一条再准也只证明这一方面。

权重错了怎么发现：强坐标里有人一看就不同的，偏松，上调 1.2 或下调 0.7；一看就同一件的只拿弱坐标，偏严，上调相容或阈值降 1.0；两边都少，多半缺维度。

## 两个验收例子

一、「2021年秋季」+「北京嘉德」对「2021年8月」+「北京市的嘉德」：两维各拿 0.7，累计 1.4，过线无冲突 → 强坐标，依据“机构名只差地点限定词，时间在同一季”。

二、「2021年秋季」对「2021年12月5日」：只有边缘相容 0.3，够不到 1.2，也不够两维 → 不是强坐标；但高于零，高于看不到证据，演示写“时间上不矛盾，但没证明这一天”。

## 已定的事

**相容可以撑强坐标。** Lodestar 不是玩文字游戏，而是替人把“收证据、判同一件”做完；人凭直觉认定同一件，不该因字面不同就否掉。原口径“相容不许升强坐标”作废。

**证据行加三个可选字段。** 为什么加：可审计，落在哪个维度、对上没有、原文什么样都能逐条回看。形态：`dimension` 形如 `porcelain:dateText`，只取注册表里的名字；`state` 取六态之一（exact、caliber、edge、conflict、mismatch、unknown）；`matchedValue` 必须是该行引文的逐字子串，否则降为 unknown。三者都可空。老行缺字段读作无从判断：不进分母、不进共现、不升坐标，只在凭据里列出；演示与评估读数会变（按字面判“没覆盖”的变成“有线索”），口径变严，须重跑后重记基线。

## 对外呈现契约

对外只发三档：强坐标、弱坐标、无坐标；冲突候选单独挂标记，不许压成“反对”。**禁止把口径相容说成“对”或“一致”**，只能说“很可能是同一件，只是说法不同”；边缘相容只能说“没有矛盾，但这不能证明”。每条结论都附“维度＋状态＋原文值”，缺凭据不许出界面。

## 时间维度与扩展

时间只是第一份实现，细节见《[时间窗口的两条口径](time-window-rules.md)》。材质（类别值）、尺寸（区间）、成色（有序档）、来源链条（集合）都能用这套状态，擦边各写各的；唯一会撞上限的是多值逐项计分（十件拍品对七件），按边缘相容，比例只进说明。架构失效条件：多数维度抽不出可回链的值就退回只展示；要联合判断就允许复合维度；跨域同名字段靠维度名带域。

## 最短实施顺序

- 加字段，先只读不写，老行按无从判断；跑类型检查。
- 抽取只输出逐字原文值并校验“是引文子串”；拿冻结案例看失败率。
- 先只做时间维度，纯函数返状态，用四条窗口读数测试。
- 按判定顺序改计分与门禁，冲突否决放在算分前；两个验收例子写成测试。
- 演示换多态文案，确认口径相容没被写成“对”；抽一条强坐标验凭据能回链。
