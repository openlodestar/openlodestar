大模型说的话，先去网上查一遍

OpenLodestar 是一个给大模型输出把关的程序。模型说的每条信息，它都当成待核实的线索，去公开网页上找证据：找到，就把原文和出处一起留下；找不到，也会写清楚是没查完、没有可用来源，还是确实不存在。

留下的每条结论，都能照着同样的步骤重跑一遍。

在 GitHub 上看代码 先读 README

OpenLodestar is a verification layer for LLM output. Every claim is treated as a lead and checked against public web pages. When evidence is found, the exact quote and its source are kept; when it is not, the result says which kind of not-found it is. Every kept verdict can be re-run step by step.

它到底在做什么

模型很容易说出一句听起来很对、但没有任何出处的话。直接信，错了也看不出来；完全不信，又没法用。OpenLodestar 把这件事变成可以检查的：有没有证据、证据是什么、够不够。

比如模型说：某拍卖行在 2026 年 5 月办过一场拍卖会。

它会去搜公开页面，找到官方场次页，确认页面里真的有这句话，再把原文和出处留下。只有一家来源时，它只给“弱”；要第二家独立来源也出现同样的事实，才会升级成“强”。

它守着三条规矩

模型先说的，只当线索

不因为一句话听起来合理就放行。每条都要过证据这一关。

证据只从外面来

不用自己采集的语料给自己作证，避免自说自话。

结论要能重跑

检索、抓页、比对、判定都留下记录。错了能定位到哪一步。

一条信息会经历什么

  1. 拿到一条说法一条说法、一个字段，不贪多。
  2. 判断怎么查能直接查就直接查，太大就拆开，查不了就当场拒绝。
  3. 去公开网页搜中英两条查询轨，尽量不漏。
  4. 把页面存下来，逐页比对模型看到的是哪份正文，就存哪份；引文必须逐字命中。
  5. 计票，决定留不留分成强、弱、拒收三档；“查不到”也分三种原因。
  6. 留下带出处的记录每条结论都带引文、页面快照和重新检查的入口。

自己跑一遍

需要 Node.js 20 和 pnpm。下面四步都在本地完成，不联网，也不需要 API key。

git clone https://github.com/openlodestar/openlodestar.git
cd openlodestar
pnpm install
pnpm run demo:real

跑完会得到一份真实公开报道案例的完整记录：说法、证据、判定和引文校验。

它不做什么

  • 不是事实数据库，也不保证模型说的都对。它只把“有没有证据、证据是什么”摆出来。
  • 不是通用事实核查器。目前只有一个古玩领域的策略包，换领域要另写规则。
  • 0.1.0 不发布到 npm，按源码或命令行运行；接口在 1.0 前可能变。

名字里的 Lodestar 是北极星：不是替你做判断，而是给你一个可以反复对照的参照点。
