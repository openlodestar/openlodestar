# 北京保利 2021 秋拍「禹贡」专场：一份来自真实页面的证据底稿

这不是一个"合成数据摆样子"的示例。四份快照都是 2026-10-29 从公开页面抓下来的真实正文，
再裁成"含引文的自然段 + 直接上下文"的节选；每条证据都带原始 URL、逐字引文、来源档位与来源家族；`pnpm run demo:real` 在断网状态下
重算裁决与门禁，把"凭什么算数、凭什么不算数"摊开给你看。

它要回答的是一个产品问题，而不是一个技术问题：

> 大模型说"北京保利 2021 年 12 月 5 日办过「禹贡Ⅰ—盛清御瓷新风尚」"——
> 这句话里哪几个字段能站住？站住的部分能不能拼成一条可用的记录？
> 拼成之后，又凭什么敢把它交给下游？

"档位"不是按网站名气拍的：官方拍卖行站是 `official`，一手报道是 `primary`，聚合站是
`aggregator`，不在白名单里的域名一律 `unlisted`。中新网在这里是 `unlisted`，所以它能给
地点提供一条支持，但不会被当成能单独裁定关键字段的权威源。

## 快照是节选，不是全文

仓库里保留的是**节选**：只留标题、署名、含引文的自然段和直接上下文，删掉导航、广告、图注、
推荐位与页脚。每份快照第一行写着「节选·非全文」，正文里的省略处用「……」标出。

这不是为了省空间，而是因为整页转载超出"适当引用"。代价是：**快照不能再当原文全文用**。
「禹贡Ⅲ」的 `not_found` 因此只覆盖这四份节选，不覆盖原文全文，更不能推出"世界上不存在"。

抓取档案在 [`snapshots/manifest.json`](snapshots/manifest.json)，逐份记着：

- **什么时候、用什么抓的**：2026-10-29 16:35–16:37（+08:00），`curl` 取服务端返回的 HTML，
  再用本地 Python `html.parser` 抽正文——没有执行页面脚本，所以留下的是服务端那一版；
- **全文长度与 SHA-256 指纹**：全文与原始 HTML 已不在仓库，指纹留着供将来重抓比对——
  重抓后哈希一致，说明原页没变；不一致，说明至少有一方变了；
- **裁掉了什么、留下了哪些行**：保留行号、删除范围、节选自身的字节数与哈希；
- **哪些没记下来**：HTTP 状态码与响应头、重定向后的最终 URL 当时没有留存，manifest 里
  标为未知，而不是补一个看起来合理的值。

第三方文字的版权归原出版方，不在 Apache-2.0 授权范围内；逐条见
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)。

## 四条记录，四种结局

| 记录 | 关键字段裁决 | 门禁 | 坐标 | 这条记录说明了什么 |
| --- | --- | --- | --- | --- |
| `rec-poly-2021-yugong-1`<br>禹贡Ⅰ · 2021-12-05 | 3 成立（E2） | `strong` | `strong` / E2 | 两个独立家族都支持，而且两家页面各自同页写到三项——共现命中 2 页 |
| `rec-poly-2021-yugong-1-nov15`<br>禹贡Ⅰ · 2021-11-15 | 2 成立 · 1 被反驳（E2） | `rejected` | — | 机构与专场名都对，但日期被两家独立来源的 12 月 5 日直接反驳 |
| `rec-poly-2021-yugong-2`<br>禹贡Ⅱ · 2021 年秋季 | 3 成立（E1） | `weak` | `weak` / E1 | 三项都成立，但只有一个独立家族；有坐标，默认不可读 |
| `rec-poly-2021-yugong-3`<br>禹贡Ⅲ · 2021 年 12 月 | 2 成立 · 1 未查到（E0） | `rejected` | — | 机构和日期是真的，但"禹贡Ⅲ"在四份节选里没有任何说法 |

第三、四条记录里的「2021-11-15」和「禹贡Ⅲ」是**注入的负样本**：它们不是这份底稿要证明的
事实，而是用来检验系统会不会把"看起来合理"当成"已经证实"。两条候选都没有产生坐标——
这不是写死的结论，是同一套 `retally → 记录门禁 → 坐标导出` 代码算出来的。

## 一个容易忽略的细节：转载不算第二个来源

澎湃号那篇文章的发布者是「雅昌艺术网」官方账号，正文也标着"原创 李保兴 雅昌艺术网"。
如果按域名计票，`m.thepaper.cn` 会被当成与 `amma.artron.net` 并列的第二个家族——于是
「禹贡Ⅱ」凭空多出一票独立支持，weak 就会被误判成 strong。

所以这一行的 `sourceFamily` 写成 `artron.net`，并在 `note` 里留下依据：

> 澎湃号「雅昌艺术网」官方账号转载原创稿（作者李保兴，雅昌艺术网）；
> sourceFamily 按原创方归并，转载不增加独立来源。

独立性数的是**谁最先说出这件事**，不是**哪个网站转载了它**。这条规则在真实数据里比在
合成数据里更容易被违反，因为转载页看起来完全像一个独立站点。

## 证据链怎么读

```
claims.jsonl        每条断言只写一个字段：机构 / 日期 / 专场名 / 地点
      │
      ▼
evidence.jsonl      每条断言 × 一个页面 = 一行证据；带逐字引文、URL、档位、家族、快照
      │
      ▼
demo 重算           按家族去重计票 → supported / refuted / conflicting / not_found
      │
      ▼
记录门禁            关键字段是否全部成立？是否有同一页同时写到全部关键字段？
      │             → strong / weak / rejected
      ▼
anchors.jsonl       只有 strong / weak 导出坐标；strong 的 sourceUrls 就是共现页
```

几个可以直接对照的位置：

- 强记录的 `sessionName` 一条，AMMA 引的是「禹贡Ⅰ—盛清御瓷新风尚」整句，The Value 引的是
  「禹貢I - 盛清御瓷新風尚」繁体写法。引擎的字形折叠与破折号归一让两种写法落到同一个键，
  但两条引文仍然各自逐字留在自己的快照里——**归一化只用于比对，不改写原文**。
- 弱记录的三个字段都只有一行证据，家族都是 `artron.net`。门禁理由会直接写"最低证据等级
  只到 E1（单一独立来源）——不给强坐标"，而不是含糊地说"证据不足"。
- 假「禹贡Ⅲ」的专场字段是 `not_found`，成因 `coverage`：不是"世界说没有"，而是"这批候选
  里没有能承载它的页面"。它的机构与日期反而都成立——这正是记录级门禁存在的理由：
  **每个字段各自为真，拼起来仍可能是一条不存在的记录**。

## 跑起来

```bash
pnpm install
pnpm run demo:real
```

输出会写到 `.openlodestar-demo/poly-2021-autumn/`，并生成一份自包含的 HTML 报告：

```
.openlodestar-demo/poly-2021-autumn/
  claims.jsonl
  evidence.jsonl
  snapshots/
  verdicts.jsonl
  records.jsonl
  anchors.jsonl
  demo-report.html      ← 浏览器直接打开，无需联网
```

报告把"一眼看懂 → 四条记录 → 每条字段的引文 → 来源表 → 硬护栏读数"排在同一页里，适合
拿给不读代码的人看。终端里还能单独跑两道硬校验：

```bash
pnpm run verify-quotes -- --data .openlodestar-demo/poly-2021-autumn
pnpm run audit         -- --data .openlodestar-demo/poly-2021-autumn
```

两条命令都只读，发现违规以退出码 1 结束：

- `verify-quotes`：每条引文必须逐字出现在它自己的快照里，并且必须写到被裁的那个字段；
- `audit`：主键引用、快照存在性、强坐标的共现页是否仍然成立。

## 这个演示没有证明什么

- 它是**冻结的离线底稿**：演示只重算已有证据，不重新检索、不重新抓取、不调用模型。
  它证明的是"给定这批证据，结论是否可复现、可核对"，不是"系统此刻能抓到这些页"。
- 四份来源都是中文公开页面；拍卖行官网与英文来源本轮没有纳入。所以「禹贡Ⅱ」只有单一来源，
  不是因为它只存在于一个网站，而是因为这批候选里只有一篇提到了它。
- 快照是抓取后裁出的正文节选，不是全文，也不是浏览器完整 DOM。原始 URL 在
  `evidence.jsonl` 与 `case.json`；抓取时间、抓取方式、全文指纹与裁剪范围在
  `snapshots/manifest.json`。
- 「禹贡Ⅲ」与「11 月 15 日」是负样本；`not_found` 说的是"这批节选里没有"，不是
  "原文里没有"，更不是"世界上不存在"。要把它升级成"确证无记录"，得先把候选来源覆盖完。

## 文件清单

```
examples/poly-2021-autumn/
  README.md            本文件
  case.json            案例卡：标题、叙事、来源表、预期结局、边界
  query.txt            产生这批记录的原始提问
  claims.jsonl         13 条原子断言（4 条记录 × 3 个关键字段，强记录多一个地点）
  evidence.jsonl       22 条证据行（每条都带逐字引文与快照引用）
  THIRD_PARTY_NOTICES.md  第三方摘录的版权与出处声明
  snapshots/           4 份节选正文（AMMA / The Value / 澎湃号 / 中新网）+ manifest.json 抓取档案
```

设计这套演示的方法论写在 [`docs/demo-design-guide.md`](../../docs/demo-design-guide.md)：
怎么从"可核对的一句话"出发、怎么用真实但冻结的素材、为什么"拒绝"比"多答一条"更能说明产品。
